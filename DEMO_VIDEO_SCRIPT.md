# TaskFlow demo video outline (about 2–3 minutes)

## Before recording

- Start the app with `node server.js` and open `http://localhost:3000`.
- Use test accounts and non-sensitive demo project names.
- Open a normal browser window for Account A and a private window for Account B.
- Close unrelated tabs and notifications.
- Do not show passwords, session cookies, personal emails, or your local database file.

## Suggested narration

**0:00–0:15 — Introduction**
"Hi, this is TaskFlow, a project management web application built with HTML, CSS, JavaScript, Node.js, Express, SQLite, and Socket.IO. It is inspired by Kanban-style tools such as Trello and Asana."

**0:15–0:35 — Authentication and projects**
Show registration/sign-in and the project selector. Say: "Users can sign in, create projects, and work within projects they have access to."

**0:35–1:05 — Tasks and board workflow**
Create a sample task, set a priority and due date, move it from To Do to In Progress and then Done, and demonstrate search/filtering. Say: "Tasks can be managed on a Kanban board, with priorities, due dates, and status updates."

**1:05–1:35 — Team collaboration**
Show a shared project, member list, and task assignment. Say: "Project members can collaborate on shared work, and tasks can be assigned to team members."

**1:35–1:55 — Comments and activity**
Open a task's comments and show recent project activity. Say: "Comments and activity history help members follow discussions and changes."

**1:55–2:20 — Real-time update**
With both accounts viewing the shared project, add or move a task in one window and show the other window updating without a manual refresh. Say: "Socket.IO sends real-time project updates to authorized members."

**2:20–2:35 — Closing**
"That is TaskFlow, a learning project focused on project organization, task tracking, and team collaboration. Thank you."

## Final checks

- Demonstrate only features that work in the submitted version.
- Keep the video clear and steady; a screen recording with voice narration is enough.
- Add the GitHub repository link and a short description when sharing on LinkedIn.
